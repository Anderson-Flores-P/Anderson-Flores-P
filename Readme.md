## 🌟 Proyecto destacado

### 📚 StudySync OS

<p align="center">
  <a href="https://studysyncos.vercel.app/">
    <img src="https://img.shields.io/badge/StudySync_OS-Visitar_Proyecto-38BDF8?style=for-the-badge&logo=vercel&logoColor=white" alt="Visitar StudySync OS">
  </a>
</p>

**StudySync OS** es una plataforma desarrollada para centralizar la gestión de tareas, asignaturas y sesiones de estudio en un solo entorno.

El proyecto nació como una solución para organizar mejor la vida académica y facilitar el seguimiento de las actividades de estudio.

#### ✨ Características

- 📚 Gestión de asignaturas.
- ✅ Organización de tareas.
- 🗓️ Control de sesiones de estudio.
- 🎯 Seguimiento de actividades académicas.
- 💻 Interfaz web enfocada en la productividad.

**Tecnologías:** Desarrollo web · JavaScript · Vercel
